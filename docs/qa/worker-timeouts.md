## Accounting and overlap limits

- Qualifying measured jobs: 63; qualifying failed-prime jobs: 4.
- Measured rows lacking per-job clocks: 40. These cannot be certified as having no slow worker job (production is uninstrumented).
- Context uses membership in beforeStory.workerJobs; new correlation IDs after that capture are story preparation. Error rows without that capture use their failure stage and are explicitly marked inferred.
- Active interval is mainDequeued → main result receive, actual timeout, or immediate non-abandoned cancellation. Abandoned caller settlement is not used as the active end. Unknown abandoned end is reported separately, never asserted to overlap.
- Overlap is strict interval intersection of normalized epoch clocks within one document/row. It proves timing overlap only; it does not prove CPU concurrency, starvation, or shared-thread ownership.
- Result handled excludes pumping the next job; full handler includes that pump. Module-ready and inbound/delivery residuals retain documented composite meanings.
